# Веб-Мессенджер

Простой мессенджер с регистрацией, входом и обменом сообщениями через файлы.

## 🌐 Демо
https://abudliphone990-droid.github.io/my-messenger/

## ✨ Особенности

- 🔐 Регистрация и вход пользователей
- 💬 Отправка и получение сообщений
- 📤 Экспорт чата в JSON файл
- 📥 Импорт чата из файла
- 🔗 Поделиться ссылкой на чат
- 📱 Адаптивный дизайн
- 💾 Локальное хранение данных

## 🚀 Как использовать

### Для одного пользователя:
1. Откройте сайт
2. Зарегистрируйтесь или войдите
3. Отправляйте сообщения - они сохранятся в вашем браузере

### Для общения с другом:
1. **Вы экспортируете чат:** Нажмите кнопку 📤 (экспорт) в чате
2. **Отправьте файл другу:** По email, мессенджеру и т.д.
3. **Друг импортирует чат:** Нажмет кнопку 📥 (импорт) в чате
4. **Обменивайтесь ссылками:** Нажмите кнопку 🔗 (поделиться)
5. **Зарегистрируйтесь под разными именами**

### Как работает синхронизация:
- Сообщения хранятся в localStorage браузера
- Для обмена между устройствами используется импорт/экспорт файлов
- Между вкладками одного браузера сообщения синхронизируются автоматически

## 🛠 Технологии

- HTML5, CSS3, JavaScript (ES6+)
- LocalStorage для хранения данных
- GitHub Pages для хостинга
- Font Awesome для иконок
