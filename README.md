# Простой Мессенджер

Веб-приложение мессенджера с регистрацией, входом и обменом сообщениями.

## Функции

- 📝 Регистрация новых пользователей
- 🔐 Вход в систему
- 💬 Отправка и получение сообщений в реальном времени
- 👥 Общение с другими пользователями
- 📱 Адаптивный дизайн для мобильных устройств
- 🔗 Поделиться чатом с друзьями

## Как развернуть на GitHub Pages

1. Создайте новый репозиторий на GitHub
2. Загрузите все файлы проекта в репозиторий
3. Перейдите в Settings → Pages
4. В разделе "Source" выберите:
   - Branch: `main`
   - Folder: `/` (root)
5. Нажмите "Save"
6. Через несколько минут ваш сайт будет доступен по адресу:
   `https://ваш-username.github.io/имя-репозитория/`

## Как использовать

1. **Регистрация:**
   - Откройте сайт
   - Нажмите "Зарегистрироваться"
   - Введите имя пользователя и пароль
   - Нажмите "Зарегистрироваться"

2. **Вход:**
   - Если у вас уже есть аккаунт, нажмите "Войти"
   - Введите свои данные

3. **Отправка сообщений:**
   - Войдите в систему
   - Введите сообщение в поле ввода
   - Нажмите Enter или кнопку отправки

4. **Поделиться чатом:**
   - Нажмите кнопку "Поделиться" в чате
   - Отправьте ссылку другу
   - Друг откроет ссылку и сможет отправлять сообщения

## Технические детали

- Сообщения сохраняются в LocalStorage браузера
- Нет серверной части - всё работает в браузере
- Поддерживаются все современные браузеры
- Адаптивный дизайн

## Важно

⚠️ **Примечание по безопасности:** Этот мессенджер предназначен для демонстрационных целей. Сообщения сохраняются только в вашем браузере и не передаются на сервер. Для реального использования требуется серверная часть и шифрование.

## Разработка

Чтобы запустить локально, просто откройте `index.html` в браузере.
